# 小5算数「整数」類題特化ドリル WEBアプリ

小学校5年生の算数単元「8. 整数」（偶数・奇数、倍数・公倍数、約数・公約数、文章題）のテスト対策WEBアプリケーションです。

## 特徴
- **原本テストの完全保全（類題特化出題）**:
  - テスト原本（『わくわく算数 5年2学期 8. 整数』）の数値そのものは出題せず、**同一パターンの類題のみを自動出題**します。
  - 事前に原本の答えを覚えてしまう心配がなく、紙面テスト本番に向けた本質的な実力養成が可能です。
- **1問1答・即時判定ドリル**:
  - 1問解くごとに即座に「せいかい！」「おしい！」を判定。
  - テスト用紙の「考え方」欄に準拠した丁寧な途中式・解法解説がその場で表示されます。
  - 「つぎの問題へ ⏩」ボタンまたは Enter キーで次々とテンポよく解いていくことができます。
- **入力式（小学生にやさしい入力ゆらぎ吸収）**:
  - 選択式ではなく、実際に数字やことばを入力させる実践形式。
  - 全角数字（１２）→半角（12）への自動変換。
  - カンマ、読点（、）、スペースなどの区切り文字に柔軟対応。
  - 順不同指定のある問題（約数リストや偶数・奇数の分類）は入力順序が違っても正解判定。
  - 用語問題は漢字・ひらがな（偶数／ぐうすう）の両方に対応。
- **連続正解（コンボ）カウンター & ご褒美「ネオン・アーケードテトリス」**:
  - れんぞく正解数や解いた問題数をリアルタイムでカウント。
  - **10問連続正解を達成すると「2分間テトリス」がご褒美としてプレイ可能！**
  - **サイバーパンク風の美しいビジュアルエフェクト**:
    - 光り輝くネオングロー（Neon Bloom）ブロック
    - どこに着地するかが一目でわかる「ゴーストピース（着地予測枠）」
    - ライン消去時の「光の粒子（パーティクル）爆発」＆「スクリーンシェイク（画面振動演出）」
    - 連続消しでの「フローティングスコアテキスト」
    - ピースを一時キープできる「HOLD（キープ）機能」（Cキーまたはボタン）
  - 2分経過すると自動で盤面が一時保存され、勉強に戻ります。
  - **次にまた10問連続正解すると、前回のテトリスの続き（同じ盤面・スコア）から再開**してプレイできます！
- **全問題からのランダム出題**:
  - 特定の簡単なジャンルに偏らず、全15パターンの類題からまんべんなく出題されます。
