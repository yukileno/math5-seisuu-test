# 小5算数「整数」類題特化ドリル WEBアプリ

小学校5年生の算数単元「8. 整数」（偶数・奇数、倍数・公倍数、約数・公約数、文章題）のテスト対策WEBアプリケーションです。

## 特徴
- **原本テストの完全保全（類題特化出題）**:
  - テスト原本（『わくわく算数 5年2学期 8. 整数』）の数値そのものは出題せず、**同一パターンの類題のみを自動出題**します。
  - 事前に原本の答えを覚えてしまう心配がなく、紙面テスト本番に向けた本質的な実力養成が可能です。
- **1問1答・即時判定ドリル**:
  - 1問解くごとに即座に「せいかい！」「おしい！」を判定。
  - テスト用紙の「考え方」欄に準拠した丁寧な途中式・解法解説がその場で表示されます。
  - 「つぎの問題へ ⏩」ボタンまたは Enter キーで次々とテンポよく解いていくことができます。
- **入力式（小学生にやさしい入力ゆらぎ吸収）**:
  - 選択式ではなく、実際に数字やことばを入力させる実践形式。
  - 全角数字（１２）→半角（12）への自動変換。
  - カンマ、読点（、）、スペースなどの区切り文字に柔軟対応。
  - 順不同指定のある問題（約数リストや偶数・奇数の分類）は入力順序が違っても正解判定。
  - 用語問題は漢字・ひらがな（偶数／ぐうすう）の両方に対応。
- **連続正解（コンボ）カウンター**:
  - れんぞく正解数や解いた問題数をリアルタイムでカウントし、学習モチベーションを高めます。
- **カテゴリ切り替え機能**:
  - 「ぜんぶ」「偶数・奇数」「倍数・公倍数」「約数・公約数」「文章題（応用）」のタブで苦手分野の集中練習も可能。
